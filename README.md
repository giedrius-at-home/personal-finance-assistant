# Finance Assistant

Local-first personal finance app for macOS, written in Rust (Tauri 2 + Leptos).
Runs entirely on the owner's Mac: bank data from Enable Banking into local
SQLite, finance logic in Rust, old data archived encrypted and compressed on
Google Drive. Updates ship as signed releases checked by the app.
